Executive Summary

Third‑party delivery apps improve reach but erode margins via 25–35% commissions. Phone orders cause errors and slowdowns. Your custom platform removes commissions, reduces mistakes, and builds a direct, valuable relationship with customers.

We’ll ship a pragmatic MVP in 8 weeks: a fast, branded ordering site and an operations console for the caisse manager with ticket printing, menu management, and core reporting. The result is an owned, scalable asset with low monthly costs.

The Opportunity

MVP Scope

Customer (Web App)

  • Browse/search menu (images, prices, categories)
  • Cart with notes and simple options/variants
  • Place order (pickup/dine-in; optional address)
  • Cash on delivery / pay at counter (online pay later)
  • Status tracking: Pending → En traitement → Prêt → Livré/Retiré
  • Responsive, fast, basic SEO; PWA-ready baseline

Cashier/Admin (Dashboard)

  • Secure login, roles (Admin, Cashier)
  • Realtime order queue, status updates, filters
  • One‑click 80mm ticket (PDF) with QR + order code
  • Menu CRUD (categories, items, prices, availability)
  • Reports: daily orders/revenue, top items; CSV export
  • Browser notifications for new orders

Architecture & Stack

Stack

  • Frontend: Next.js (React), TailwindCSS, React Query, Next Intl (i18n)
  • Backend: Next.js API routes or Node.js (Express/Nest)
  • DB: PostgreSQL (Supabase / Neon / Railway)
  • Realtime: Supabase Realtime / WebSockets
  • Auth: Supabase Auth or NextAuth (email/password + OTP optional)
  • Email: Resend/SendGrid (transactional)
  • Monitoring: Sentry, UptimeRobot; CDN/DNS: Cloudflare
  • Deploy: Vercel (serverless) or Docker on VPS (DO)
