Executive Summary

  • Goal: Replace Cartway with an owned platform, keep monthly ≤ current spend (≈640 MAD for 2 restaurants), then drop after ownership.

Architecture & Security (Budget MVP)

Architecture

  • Frontend: React SPA (web ordering) + web dashboard
  • Backend: Node.js (Express) REST + realtime events
  • Database: MongoDB (Atlas free tier or VPS)
  • Hosting: VPS (cost‑effective); domain included
  • Media/CDN: object storage for images
  • Printing: browser print (80mm PDF) with print CSS

Security

  • HTTPS (TLS), HSTS; strong password hashing
  • JWT auth + role‑based access for admin
  • Server‑side pricing and inventory validation
  • Rate limiting, CORS, CSRF protections
  • Automated daily backups; 7–30 day retention

Negotiation Angles

  • Match/Beat monthly now: Option 1 keeps total ≤ 640 MAD/month, then drops to ~120.
  • Ownership: Stop renting after 24 months; own code + data.
  • Multi‑branch efficiency: One platform runs both restaurants; ops cost doesn’t double.
  • Phased complexity: Launch COD + PDF now; add POS printing + CMI later.
